# BandBUDDY outcomes

- [ ] **Event-based setlist workspace:** Create and manage event-based setlists from a clear dashboard; the workspace shows the event name, date/venue context, song count, running time, and completion status in a responsive layout.
- [ ] **Collaborative membership:** Invite bandmates to shared setlists so members can collaborate on the same event material; show clear member presence and recent changes so collaborators understand who updated the setlist.
- [ ] **Song entries:** Add, edit, and remove songs with a song name and video link; display embedded or linked song videos directly from each song entry.
- [ ] **Key decisions:** Each song has two separate key controls: a source-key control for the automatically detected key suggestion from the referenced video and a performance-key control where the singer manually chooses the intended key.
- [ ] **Running order:** Reorder songs within a setlist to define the running order for the event.
- [ ] **Smooth experience:** Provide responsive, smooth navigation and editing across desktop and mobile devices with a solid, beautiful UI that is easy to navigate.
- [ ] **Persistence foundation:** Store users, bands, setlists, songs, members, and activity in the managed relational database with typed server procedures for collaborative reads and writes.
